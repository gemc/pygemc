# PYGEMC Release 0.6.0

Upcoming in the next release. Changes since `v0.5.0`.

<br/>

# Release notes

- Limit Python support to 3.10-3.14 while retaining the required `pymeshlab` dependency.

<br/>

## Documentation

- Documented the DRelease-based nightly workflow, automatic tag-date notes, and publication settings.
- Documented the `latest` (PyPI) and `dev` (editable checkout) install modes in the README installation
  section.

<br/>

## Tests

- Added offline environment and installer checks for supported Python versions, environment reuse
  and backups, staged install prefixes, the skip flag, and pip failure propagation.
- Replaced duplicated nightly release steps with `gemc/DRelease@v1`, using full Git history and
  commits after the latest version tag's date instead of a fixed start date. Publication is serialized,
  and notes are generated in the runner's temporary directory before updating the `dev` tag.
  Retained nightly prerelease recreation.

<br/>

## Detailed list of changes and fixes

- Centralize environment preparation, dependency installation, and Meson install-hook
  registration in pygemc; export the build interpreter for consuming projects.
- Select a supported Python during Meson setup and preserve existing environments before switching
  interpreter versions. Document Python 3.14 setup on macOS.
